On Linux and macOS, authority initialization and status can reach the running
server through a Unix socket inside the private authority directory, authenticated by
kernel peer credentials in both directions. Temporary contention without a live
endpoint retains the busy diagnostic; unsafe endpoints still fail explicitly. Existing commands retain stopped-instance operation. Control messages,
connections and work are bounded, and shutdown keeps the instance lock until
actual administrative work finishes. Run commands as the server's OS account;
loopback HTTP and socket-path knowledge do not grant administrative authority.
