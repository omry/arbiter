Bound total retained artifact storage across plugins to a configurable 1 GiB
default using `arbiter.limits.max_artifact_storage_bytes`. Count payload and
metadata bytes, reclaim expired or incomplete artifacts before admission, and
coordinate concurrent creators across processes, including prolonged Windows
lock contention. Reject temporary capacity exhaustion with HTTP 503,
`resource_exhausted`, and transient retry guidance. Artifacts whose payload plus
reserved metadata exceeds an empty store's cap return HTTP 403, `policy_denied`,
and non-transient guidance. Roll back
failed writes so they do not strand capacity. Existing artifacts created without
metadata access headroom remain inspectable and downloadable at a full or
lowered quota, and interrupted metadata replacements are reclaimed before
retained-byte accounting.
